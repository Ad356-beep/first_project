EAFC 26 Website
Project Description

This project is a basic multi-page website about EAFC 26. It includes information about gameplay features, promos, game modes, and products. The goal of the project is to demonstrate the use of HTML, CSS, and simple JavaScript on a structured website.

Installation Instructions

No installation is required.

To view the project:

Download or clone the project folder.

Open any of the HTML files (such as index.html) in a web browser.

All styling and scripts are included locally.

Usage Instructions

Use the navigation bar to move between pages of the site.
The Promos page includes an image gallery and a button that uses JavaScript to reveal a tip.
You can edit the appearance by modifying the project.css file or change content by editing the HTML files.
